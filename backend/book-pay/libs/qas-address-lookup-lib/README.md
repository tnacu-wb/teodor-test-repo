# QAS Address Lookup Library
This library contains the Java classes generated from Experian's Address Validate SOAP API.
It is intended for use from services aligned to Spring Boot 4.0.3 and Java 25.

# Technologies
 - Java 25
 - Maven 3+
 - Docker 0.12+
 - Docker-compose v1+
 - Apache CXF Plugin v4.2.0
