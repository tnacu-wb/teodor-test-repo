# Getting Started

- Run:
  
  ```bash
  git clone git@github.com:whitbread-eos/pi-front-end-applications.git
  ```


- In order to install all the project dependencies you have to request access to the below repositories. This should not be needed once all the below repositories are imported as npm packages:
    - whitbread-eos/whitbread-versioning;
    - whitbread-eos/whitbread-ui-kit;
    - whitbread-eos/pi-aem-fe-package-build;
    - whitbread-eos/Mega-Code;
    - whitbread-eos/dom-library;


- Other requirements: `NodeJS v24.20.0`


- In order to continue you have to create a Personal Access Token (PAT) on [GitHub](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/creating-a-personal-access-token).


- Create a `~/.npmrc` file in your user's root directory and add to it this line `//npm.pkg.github.com/:_authToken=${authToken}` where `${authToken}` will be replaced with your token


- After cloning the project, in the root directory run:
    - `npm login --scope=@whitbread-eos --registry=https://npm.pkg.github.com` (when asked, enter your GitHub username (all lowercase), your PAT instead of a password, and your Whitbread email address)
    - Follow the below 3 steps to login from local
      - Download these three files from [here](https://whitbreadis.atlassian.net/wiki/spaces/DSA/pages/4464869411/Enable+login+work+from+localhost+for+Premier+Inn+and+Business+Booker#Login-to-PremierInn) and add it in /apps/next-apps/**premier-inn**/public folder
      - Download these three files from [here](https://whitbreadis.atlassian.net/wiki/spaces/DSA/pages/4464181349/Login+to+Business+Booker+from+local) and add it in /apps/next-apps/**business-booker**/public folder
      - Make sure .env.local file of premier-inn and business-booker apps have the variable - `NEXT_PUBLIC_SECURE2_URL="http://localhost:3000"`
    - `nvm use 24.20.0`
    - `yarn`
    - `yarn type-generate --local`
    - `yarn build:atomic:components`
    

- As shortcut for the last three commands above you can also use `yarn build:all`
- If you are seeing permission errors during installation, but have access to the repository in question (e.g. by visiting it in a browser),
  you may need to add `ssh.github.com` to your known hosts first. To do so, run

  ```bash
  ssh-keyscan -H ssh.github.com >> ~/.ssh/known_hosts.
  ```

 - For PIBA Dashboard. A mock server needs to be started
    From the root of the project. Find the directory ROOT_OF_PROJECT/common/koa-mock-api/
    (There are many common folders but target the one in the Root)
      ```
      cd ROOT_OF_PROJECT/common/koa-mock-api/
      ```
    Run the following command based on which app you want to start
      ```
      yarn start:pi
      yarn start:bb
      yarn start:ccui
      ```

## Hashing a Field

To hash a string using the `hashString` function, you must use one of the values from the `HashType` enum.

```typescript
import { hashString, HashType } from 'relevant_places';

async function exampleUsage() {
  const input = 'example@example.com';
  
  // Hash using SHA-256
  const hash256 = await hashString(input, HashType.SHA256);
  console.log('SHA-256 Hash:', hash256);

  // Hash using SHA-384
  const hash384 = await hashString(input, HashType.SHA384);
  console.log('SHA-384 Hash:', hash384);

  // Hash using SHA-512
  const hash512 = await hashString(input, HashType.SHA512);
  console.log('SHA-512 Hash:', hash512);
}

// Calling the function
exampleUsage();
```

# Figma MCP Server Setup (Kiro CLI)

This project includes a Figma MCP server configuration at `.kiro/settings/mcp.json`, enabling Kiro CLI to read Figma designs and generate matching code.

## Setup

1. **Generate a Figma Personal Access Token**  
   Go to https://www.figma.com/developers/api#access-tokens and create a token.

2. **Set the environment variable**
   ```bash
   export FIGMA_ACCESS_TOKEN="your-figma-token-here"
   ```

3. **Start Kiro CLI**  
   The Figma MCP server will connect automatically. Kiro can then inspect Figma files, read component properties, layouts, and styles to generate matching code.

## Usage
